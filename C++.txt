REFERENCES AND MEMORY ADDRESSES : 
** #include <iostream>
** #include <string>
** using namespace std;

** int main(){
**      string food  = "Pizza";      -----> creates a memory space with 'Pizza' and that value is referenced with 'food'
**      string &meal = food;         -----> Here if u use 'meal = "Pizza"', it would have created a new memory space with "Pizza" again.
**      cout << food << "\n";               by using '&meal = food', we are saying meal = whatever was 'food' pointing to. THus we are
**      cout << meal << "\n";               saving memory.
**      cout << &meal << "\n";

**      cout << "-------------------------\n";
**      meal = "Burger";             -----> If we change 'meal = "Burger"' or 'food = "Burger"', both the food and meal values change.
**      cout << food << "\n";
**      cout << meal << "\n";
**      cout << &meal << "\n";
**      return 0;
** }

OOPs Friend Keyword:
    Usually, the private memebers of a class can be accessed and changed using public methods like getters and setters.
    But in some cases, you can use a special function called 'friend' function to access them directly.
    A "friend" function is not a memeber of a class, but is allowed to access the class's private data.
** #include <iostream>
** #include <string>
** using namespace std;

** class Employee{
**      private:
**          int salary;
**      public:
**          Employee(int s){
**              salary = s;
**          }
**          friend void displaySalary(Employee emp) -----> Declared Here
** };

** void displaySalary(Employee emp) { -------------------> Defined Here
**      cout << "Salary: " << emp.salary << "\n"; -------> It can access the employee salary
** }

** int main() {
**      Employee myEmp;
**      displaySalary(myEmp);
**      return 0;
** }
